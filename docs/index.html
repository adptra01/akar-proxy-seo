Akar Proxy SEO

Saluran rilis otomatis untuk plugin WordPress. Halaman ini statis; isinya hanya dua artefak di bawah.

  • akar-proxy-seo.json — manifest auto-update (dibaca plugin: versi, download_url, changelog, sha256)
  • akar-proxy-seo.zip — paket plugin siap unggah di Plugins → Add New → Upload Plugin

Kode sumber, dokumentasi, dan cara merilis: github.com/adptra01/akar-proxy-seo.
